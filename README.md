# Harry-Potter
# 🪄 哈利波特魔法世界官网

一个精美的哈利波特主题品牌展示页面，致敬魔法世界的神奇魅力。

## ✨ 项目特色

- 🎨 **沉浸式视觉体验** - 暗色主题配合魔法世界风格设计
- 📱 **响应式布局** - 适配不同屏幕尺寸
- 🧙 **丰富的内容展示** - 包含新闻、测验、拼图等魔法世界内容
- 🎄 **节日主题** - 圣诞特别版设计
- 🔍 **交互式导航** - 完整的网站导航系统

## 🖼️ 页面预览

### 主要板块

1. **品牌展示区**
   - 巫师世界 Logo 动画
   - 节日主题文字介绍
   - 互动按钮引导

2. **特色内容卡片**
   - 圣诞大型测验
   - 魔法圣诞观影推荐
   - 节日晚餐测验

3. **精彩专题**
   - 哈利波特圣诞礼物指南
   - 专属画像制作器
   - 圣诞节日装扮

4. **最新资讯**
   - 悉尼哈利波特主题灯光展
   - 德国魔法视觉艺术展
   - 纽约哈利波特商店活动

5. **互动游戏**
   - 填字游戏
   - 单词搜索
   - 谜语挑战

## 🚀 快速开始

### 本地运行

1. **克隆仓库**
```bash
git clone https://github.com/y1733133864/Harry-Potter.git
```

2. **打开页面**
   - 直接双击 `哈利波特.html` 文件
   - 或在浏览器中打开该文件

3. **确保资源完整**
   - 保持 `imges` 文件夹与 HTML 文件在同一目录
   - 检查所有图片资源是否齐全

### 在线访问
部署后可通过以下方式访问：
- GitHub Pages: `https://y1733133864.github.io/Harry-Potter`

## 🔧 自定义修改

### 修改背景图片
```css
.background-image>img {
    /* 替换图片路径 */
    src: url("你的图片路径");
}
```

### 修改主题色
```css
:root {
    --primary-color: #514a92;  /* 魔法紫 */
    --bg-dark: #10141b;         /* 深色背景 */
    --nav-bg: #242633;          /* 导航栏颜色 */
}
```

### 添加新内容
1. 在 `imges` 文件夹添加新图片
2. 复制现有卡片结构
3. 修改图片路径和文字内容

## ⚠️ 注意事项

1. **图片资源**：确保所有图片文件存在于 `imges` 文件夹中
2. **路径问题**：建议使用相对路径引用资源
3. **编码格式**：文件使用 UTF-8 编码
4. **外部链接**：部分导航链接为 `#`，需要根据实际需求替换
